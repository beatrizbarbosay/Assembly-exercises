# ⚙️ Computer Organization & Assembly — MC404

**RISC-V Assembly · C · Low-Level Programming**  
Hands-on labs from **MC404 — Computer Organization and Assembly Language** at **UNICAMP** 🇧🇷

A collection of 11 exercises exploring how software interacts with the processor: registers, memory, system calls, binary operations, and low-level algorithms.

## 🧩 Labs

| Lab | Focus |
|:--|:--|
| [01](lab01) | C with inline RISC-V assembly and Linux system calls |
| [02](lab02) | Bitwise operations, shifts and registers |
| [03](lab03) | Low-level C, assembly and input/output |
| [04](lab04) | Integer representation and bit manipulation |
| [05](lab05) | Arithmetic and geometric calculations in assembly |
| [06](lab06) | Numeric parsing and arithmetic in RISC-V |
| [07](lab07) | Polynomial integration and subroutines |
| [08](lab08) | PGM image manipulation and bit-level data extraction |
| [09](lab09) | String routines, conversion and linked-list search |
| [10](lab10) | Recursion: factorial, Fibonacci and Tower of Hanoi |
| [11](lab11) | Memory-mapped I/O and robot motor control |

## 🛠️ Tech

`RISC-V Assembly` · `C` · `Linux syscalls` · `Computer Architecture`

> These files are academic exercises developed for the course, not a single executable application. Some labs depend on the specific RISC-V tools or simulation environment provided in class.
